统计口径
  • 社区参与账号按观测到的 PR、Issue 和非机器人 PR 评论账号去重。合入贡献者为至少有一个 PR 已合入的账号。
  • 协作讨论统计非作者、非已确认机器人账号的 PR 评论，其中 74 条为行内评论。
  • PR 按目标分支归属，发起账号按分支去重。全仓 PR 含 6 个目标分支当前已不在远端的 PR。Issue 按有记录的正式关联归属，0 表示未记录到关联。
  • 代码量按源代码行统计。行业净增扣除共同基线继承代码与同内容复制，删除冲减净增。1 万行等于 10,000 行。
  • 分支贡献者按 PR 目标分支和 AtomGit 发起账号统计，所有状态的 PR 都计入提交数。账号在各分支内独立统计。

四类代码构成

四类均使用 cloc 计入的有效行数，扣除空行和识别到的注释。

  • 源码行包括原统计口径识别的程序代码和脚本，例如 Java、Python、TypeScript，扣除单列的测试行。
  • 测试行统计测试目录或符合测试文件命名的源码，例如 tests/、test_*.py、*Test.java、*.spec.ts。
  • 配置行按文件用途估算，计入 YAML、TOML、Maven 描述文件、依赖清单及可识别的 JSON 或 XML 配置。排除样本数据、预置数据和依赖锁文件。
  • 文档行按文件用途估算，计入 Markdown、reStructuredText、AsciiDoc 和可识别的说明文本，例如 README、许可证和第三方软件声明。

common 展示完整存量。行业分支和版本分支剔除 common/ 后，与各自的 main 共同祖先比较净增量。行业源码行加测试行对应总览的行业有效代码。配置和文档基于已计数的文件，尚未逐一核验换路径后的原样复制和未被 cloc 计数的文件。
